# MEMORIAL JOURNEY — 메모리얼 여정

프리미엄 웰다잉 · 생전장례식 종합 솔루션 소개 홈페이지 (정적 프로토타입)

## 파일 구성
| 파일 | 역할 | 주소 |
|---|---|---|
| `index.html` | 메인 | `/` |
| `story.html` | 이야기(사례) 상세 | `/story.html` |
| `packages.html` | 패키지 비교 · FAQ | `/packages.html` |

## 기술 메모
- 외부 의존성: Google Fonts(Noto Serif KR, Cormorant Garamond), Pretendard CDN
- 빌드 과정 없음 — 정적 HTML 3개만 업로드하면 동작
- 사진은 전부 CSS 플레이스홀더(`.plate` 클래스) — 촬영본으로 교체 필요
- 폼(엔딩노트 신청)은 프론트 시뮬레이션 — 실제 수집은 별도 연동 필요

## 오픈 전 교체해야 할 항목

- [ ] 개인정보처리방침 · 이용약관 페이지
- [ ] 환불 규정 — 실제 계약서 기준과 일치하는지 반드시 확인
